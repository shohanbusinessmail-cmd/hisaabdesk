## যাচাইয়ের নিয়ম

1. কোড লেখা = কাজ শেষ নয়; compile + test + lint পাস = যাচাইকৃত।
2. APK তৈরি = ইনস্টল যাচাই নয়।
3. CI workflow থাকা = CI পাস নয় — রান আইডি দিয়ে প্রমাণ।
4. যা চালানো হয়নি, তা "চালানো হয়নি" হিসেবেই রিপোর্ট।

## মাইলফলক কাঠামো

- Gradle + কম্পাইলযোগ্য স্কেলেটন → কোর ডেটা → UI ফিচার → টেস্ট → CI → রিলিজ।
