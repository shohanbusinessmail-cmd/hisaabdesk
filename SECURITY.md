# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | ✅ |

## Reporting a vulnerability

Please email **helloiamshohan@gmail.com** with details. Do not open a public issue for
security problems. We aim to respond within 7 days.

HisaabDesk is an offline app: it has no INTERNET permission, no analytics and no
backend. The main security surface is local data protection, PIN handling and the
encrypted backup format. See [docs/SECURITY.md](docs/SECURITY.md) for the full model
and its documented limitations.
